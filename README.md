# 🔐 Nishat's Password Generator

A beginner-friendly Python project that generates random passwords using letters, numbers, and symbols. Users can customize the number of letters, symbols, and numbers they want in their passwords.

## ✨ Features

- 🔤 Customize the number of letters.
- 🔢 Choose how many numbers to include.
- 🔣 Add symbols to make passwords more varied.
- 🔀 Shuffle characters to randomize their order.
- 🐍 Built using Python's built-in `random` module.

## 🛠️ Technologies Used

- **Python 3**
- **Random Module**

## 🚀 How to Run

1. Clone this repository:

   ```bash
   git clone https://github.com/YOUR-USERNAME/password-generator-python.git
   ```

2. Navigate to the project folder:

   ```bash
   cd password-generator-python
   ```

3. Run the Python script:

   ```bash
   python main.py
   ```

   Replace `main.py` with your actual Python filename if it is different.

## 💻 Example Usage

